# efortune.tech Website

A professional, SEO-optimized static website for a technical consulting firm.

## Features

- **Multi-page structure** optimized for search engines
- **Semantic HTML5** with proper heading hierarchy
- **Full SEO implementation**:
  - Unique title tags and meta descriptions on every page
  - Open Graph and Twitter Card meta tags
  - JSON-LD structured data (Organization, Article)
  - Canonical URLs
  - XML sitemap
  - robots.txt
- **Responsive design** (mobile, tablet, desktop)
- **Modern dark theme** with teal accents
- **Performance-conscious** markup (no heavy frameworks)
- **Accessible** form labels and ARIA attributes
- **Contact form** ready for integration (Formspree, Netlify, etc.)

## Pages

- `index.html` — Home with hero, services overview, case studies, testimonials
- `services.html` — Detailed service offerings and engagement models
- `case-studies.html` — Project outcomes and results
- `about.html` — Company approach and leadership
- `insights.html` — Blog/insights listing
- `insights/cloud-architecture-trends.html` — Full SEO-optimized article
- `contact.html` — Contact form and information

## Deployment

This is a static site. Deploy to:

- **Netlify** (recommended — free tier, forms support, automatic HTTPS)
- **Vercel**
- **GitHub Pages**
- **AWS S3 + CloudFront**
- Any static hosting provider

### Quick Start with Netlify

1. Upload the folder or connect a Git repository
2. No build command needed
3. Publish directory: root of this folder

## Customization

- Update company name, contact details, and location throughout the HTML files
- Replace placeholder domain (`efortune.tech`) with your actual domain
- Connect the contact form to a backend service
- Add more insights/articles for ongoing SEO content
- Update `sitemap.xml` when adding new pages
- Replace images in `/images` as needed

## SEO Notes

- Update the canonical URLs and Open Graph URLs to match your production domain
- Submit `sitemap.xml` to Google Search Console and Bing Webmaster Tools
- Consider adding more long-form content pages targeting specific keywords
- Image alt text is included throughout for accessibility and SEO
